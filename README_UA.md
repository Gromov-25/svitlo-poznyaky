# ⚡ СВІТЛО | ПОЗНЯКИ ²⁴/⁷

Автоматична перевірка статусу відключень ДТЕК для:
- вул. Драгоманова, 42
- вул. Драгоманова, 42А

Повідомлення надсилаються в `@Poznyaky_Svitlo24`, коли дані ДТЕК змінюються.
Перевірка запускається GitHub Actions за розкладом приблизно раз на 10 хвилин.

## Важливо про точність

Цей проєкт читає статус, який публікує ДТЕК. Це **не датчик напруги** і не гарантує, що світло фізично є або відсутнє в кожній квартирі. Сайт ДТЕК може оновлюватися із затримкою; якщо дані недоступні або будинок не знайдений, бот нічого не вигадує і завершує перевірку з помилкою.

## Що потрібно один раз налаштувати

1. Створити GitHub-репозиторій і завантажити в нього всі файли з цього архіву, включно з прихованою папкою `.github`.
2. У GitHub відкрити **Settings → Secrets and variables → Actions → New repository secret**.
3. Створити секрет `BOT_TOKEN` і вставити токен від BotFather. Не вставляйте токен у код, README, Issues або повідомлення.
4. Переконатися, що бот `@SvitloPoznyakyBot` є адміністратором каналу `@Poznyaky_Svitlo24` і має право публікувати повідомлення.
5. Відкрити вкладку **Actions**, дозволити запуск workflows, вибрати **DTEK address monitor** і натиснути **Run workflow** для першої перевірки.

## Якщо не знаходить адресу

У ДТЕК назва вулиці може відрізнятися від короткого побутового написання. У такому разі перевірте точну назву на офіційному сайті ДТЕК і змініть `DTEK_STREET_HINT` у `.github/workflows/check.yml`. Так само можна змінити `DTEK_CITY`, якщо сервіс вимагає інший варіант назви міста.

## Примітка про запуск

GitHub Actions запускає заплановані завдання не гарантовано рівно по хвилинах; можливі затримки. Для важливих рішень щодо електробезпеки орієнтуйтеся на офіційні повідомлення ДТЕК і фактичну ситуацію в будинку.
